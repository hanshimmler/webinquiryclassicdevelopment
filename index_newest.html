NEW: AKos inquiry Android phone and tablet app
NEW:
 AKos inquiry Android phone and tablet app
The app allows you to perform the identical tasks as our webpage with some extensions such as reusable search history, chemical intelligent auto-completion (PubChem), possibility to save contact information. The app supports so-called mobile deep linking for PubChem/ChemSpider and ChemExper AKos links. That means that clicking an AKos compound vendor link on e.g. PubChem/ChemSpider/ChemExper web pages opens the app instead of using a browser to open a web page.
Currently, the app can only be installed via a download APK file. We provide a webpage with a download link for the app installer file and detailed information about the installation process and information about the app itself.
